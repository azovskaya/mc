Настройка точки

Бэкенд (Google Sheets) уже подключён. Заполните данные точки — это попадёт в журнал каждой выдачи.

Как поменять бэкенд (для администратора)

1. Создайте Google Таблицу.
2. Расширения → Apps Script → вставьте код из public/apps-script/Code.gs.
3. Запустите функцию setupSheets.
4. Развернуть → Веб-приложение, доступ: Все. Скопируйте URL /exec.
5. Откройте public/kiosk.html, замените константу API_URL на ваш URL, перезагрузите.
